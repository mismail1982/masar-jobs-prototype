# مسار — مساعد البحث عن الوظائف

النسخة المنشورة من نموذج «مسار». ملفات الموقع موجودة في مجلد `docs` ويُعاد نشرها تلقائيًا عبر GitHub Pages عند تحديث الفرع الرئيسي.

## دورة التحديث

1. تطوير واختبار النسخة داخل المشروع المحلي.
2. نسخ إصدار `dist` المعتمد إلى `docs`.
3. رفع التحديث إلى الفرع `main`.
4. يظهر الإصدار الجديد على رابط الآيفون وTelegram Mini App نفسه.

> النسخة الحالية نموذج واجهة تجريبي. إرسال OTP والتقديم على الوظائف ما زالا محاكاة حتى إضافة الخادم وقاعدة البيانات والتكاملات الرسمية.
